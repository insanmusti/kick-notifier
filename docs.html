Firefox için .xpi dosyasını, Chromium tabanlı tarayıcılar için zip arşivini GitHub Releases bölümünden indir.

Firefox — .xpi ile kurulum

  1. GitHub releases sayfasından en güncel .xpi dosyasını indir.
  2. about:addons adresini yazıp Enter'a bas.
  3. Sağ üstteki Ayarlar menüsüne tıkla.
  4. Dosyadan eklenti yükle... seçeneğini seç.
  5. .xpi dosyasını seçip Ekle'ye bas.

Firefox AMO sayfası →

Chromium — geliştirici moduyla kurulum

  1. GitHub releases sayfasından zip dosyasını indir ve bir klasöre çıkart.
  2. chrome://extensions adresine gir.
  3. Sağ üst köşedeki Geliştirici modu anahtarını aç.
  4. Paketlenmemiş öğe yükle (Load unpacked) butonuna tıkla.
  5. Çıkarttığın kick-takipci-chromium klasörünü seç.
