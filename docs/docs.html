Releases bölümünden indirip tarayıcına yükle.

Firefox için .xpi, Chromium tabanlı tarayıcılar için .crx dosyasını GitHub Releases bölümünden indir.

Firefox — .xpi ile kurulum

  1. GitHub releases sayfasından en güncel .xpi dosyasını indir.
  2. about:addons adresini yazıp Enter'a bas.
  3. Sağ üstteki Ayarlar menüsüne tıkla.
  4. Dosyadan eklenti yükle... seçeneğini seç.
  5. .xpi dosyasını seçip Ekle'ye bas.

Firefox releases sayfası →

Chromium — .crx ile kurulum

  1. GitHub releases sayfasından en güncel .crx dosyasını indir.
  2. chrome://extensions/ adresini yazıp Enter'a bas.
  3. Sağ üstten Geliştirici modunu aç.
  4. .crx dosyasını sayfaya sürükleyip bırak.
  5. Eklemeyi onayla ve eklentiyi kullanmaya başla.
