Kurulum rehberi

Releases bölümünden indirip tarayıcına yükle.

Eklentiyi kullanmaya başlamak için uygun dosyayı GitHub Releases bölümünden indirin. Firefox için .xpi, Chromium tabanlı tarayıcılar için .crx dosyasını kullanın.

Firefox

.xpi ile kurulum

  1. GitHub releases sayfasından en güncel .xpi dosyasını indirin.
  2. Firefox tarayıcınızı açın.
  3. about:addons adresini yazıp Enter tuşuna basın.
  4. Sağ üstteki Ayarlar menüsüne tıklayın.
  5. Dosyadan eklenti yükle... seçeneğini seçin.
  6. İndirdiğiniz .xpi dosyasını seçip Ekle butonuna basın.
Firefox releases
Chromium

.crx ile kurulum

  1. GitHub releases sayfasından en güncel .crx dosyasını indirin.
  2. Chrome, Edge, Brave veya benzeri tarayıcıyı açın.
  3. chrome://extensions/ adresini yazıp Enter tuşuna basın.
  4. Sağ üstten Geliştirici modunu açın.
  5. .crx dosyasını sürükleyip bırakın.
  6. Eklemeyi onaylayıp eklentiyi kullanmaya başlayın.
